
# Programming for AI — Lab Assignments

A collection of practical Machine Learning and Artificial Intelligence lab projects developed as part of the BS Artificial Intelligence program.

This repository contains two lab assignments covering six practical projects, from fundamental machine learning algorithms to end-to-end ML engineering.

## Repository Structure

### 1. ML Lab Assignment

| Project | Description |
|---|---|
| Project 1 | House Price Prediction using Regression |
| Project 2 | Image Classification using Feature Engineering |
| Project 3 | Computer Vision: Face Detection, ORB, SIFT and Hough Transform |

### 2. Mid-Term Lab Assignment

| Question | Description |
|---|---|
| Q1 | Multiple Linear Regression from Scratch |
| Q2 | Random Forest Experiments and Model Comparison |
| Q3 | Adult Income Classification and ML Deployment |

## Project Structure

Each project contains its own source code, notebooks, documentation, requirements, and generated results where applicable.

## Dataset Information

Datasets are not included in this repository.

Please refer to the dataset download guides and individual project READMEs for original sources and setup instructions.

## How to Run

1. Open the required project folder.
2. Create and activate its virtual environment.
3. Install dependencies using its requirements.txt.
4. Download and place the required dataset.
5. Follow the project's README instructions.
6. Run the Python scripts or Jupyter notebooks.

## Reproducibility

Each project has independent dependencies and execution instructions.

Results and performance metrics should be reproduced using the supplied datasets and source code.
